# ScanbotSDK Native Wrapper for iOS

Swift Package Manager repository for the iOS [Scanbot SDK Native Wrapper](https://scanbot.io/sdk).

This SPM package is not intended for direct use. It is used internally by the Scanbot SDK to provide the native wrapper functionality for the iOS platform.
If you want to use the Scanbot SDK in your iOS project, please refer to the [Scanbot SDK documentation](https://docs.scanbot.io/ios/document-scanner-sdk/introduction/) for proper integration instructions.
